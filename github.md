GitHub Features



1\. Repositories – Store and manage code.

2\. Branching – Work on features separately.

3\. Pull Requests – Propose and review changes.

4\. Issues – Track bugs and tasks.

5\. Actions – CI/CD automation workflows.

6\. Projects – Manage tasks using boards.

7\. Wiki – Documentation support.

8\. GitHub Pages – Host static websites.

9\. Code Review – Collaborate and review code.

10\. Security Alerts – Detect vulnerabilities.
